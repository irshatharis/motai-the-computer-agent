# MotAi - The Computer Agent

MotAi is a computer agent that can use the computer to accomplish tasks. It's a WIP simple agent I'm trying to build to see how far I can take it. It will probably never work but it's fun to try.

## How to use

```bash
# create a .env file and add your OpenRouter API key
eg: OPENROUTER_API_KEY=your-api-key

# install dependencies
npm install

# start the agent
npm run start "Open Brave and go to youtube.com"
```
